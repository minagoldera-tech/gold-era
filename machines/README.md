# نظام ماكينات GOLD ERA

نسخة الويب من نظام إدارة الماكينات والصيانة لمصنع GOLD ERA: كتالوج الماكينات بأكوادها، جدول الصيانة الدورية، جدول السلامة والصحة المهنية، وسجل أعمال الصيانة.

## محتوى المستودع

| الملف | الوصف |
|---|---|
| `index.html` | صفحة النظام (تعمل مباشرة على GitHub Pages) |
| `data/data.json` | كل البيانات: الماكينات، الصيانة الدورية، السلامة، السجل، وتاريخ آخر مزامنة |
| `photos/` | صور الماكينات باسم كود كل ماكينة |

## التشغيل على GitHub Pages

1. ارفع محتوى هذا المجلد إلى المستودع (الفرع `main`).
2. من **Settings ← Pages** اختر **Deploy from a branch**، الفرع `main` والمجلد `/ (root)`، ثم **Save**.
3. بعد دقيقة يظهر رابط الموقع بالشكل: `https://<اسم-الحساب>.github.io/<اسم-المستودع>/`

## المزامنة

- النسخة الأساسية للتعديل هي نظام الماكينات على Claude (إضافة وتعديل ورفع ملفات وتحديث حالة الصيانة).
- موقع GitHub نسخة للعرض والمشاركة تُحدَّث من النظام الأساسي بتحديث ملف `data/data.json` وصور `photos/`.
- تاريخ آخر مزامنة يظهر أعلى يسار الصفحة.
- كل الجداول قابلة للتحميل Excel من الموقع.

> ملاحظة: المستودع العام (Public) يجعل البيانات متاحة لأي شخص لديه الرابط. لو البيانات داخلية، اجعل المستودع خاصاً (Private) — GitHub Pages للمستودعات الخاصة يحتاج خطة GitHub Pro أو Team.
