ضبط الاتصال بقاعدة البيانات — مرة واحدة فقط

1
أنشئ مشروع Firebase مجاني
اذهب إلى Firebase Console وأنشئ مشروعاً جديداً، ثم فعّل Realtime Database واختر "Start in test mode".
console.firebase.google.com
2
احصل على Firebase Config
Project Settings → Your Apps → أضف Web App → انسخ الـ config object كاملاً (من { حتى })
3
الصق الـ Config أدناه
الصق كائن الـ config كاملاً كما هو من Firebase.
لا تحتاج سيرفر — Firebase مجاني حتى 1GB بيانات و 10GB نقل شهرياً
